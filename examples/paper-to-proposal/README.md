# Worked example: from a weak claim to a falsifiable proposal

**Everything in this directory is synthetic teaching material. There were zero real model/API calls and zero real research experiments behind these demo reading and review records.** The source text is first-party and may be redistributed under MIT.

Read in order:
1. [Original source](source-paper.md): a small exact-key cache example with an appendix counterexample.
2. [Reader A](reader-a.md) and [Reader B](reader-b.md): what two independent reading records could look like; these are authored demonstrations, not actual model outputs.
3. [Receipts](receipts.json): explicit synthetic status, zero actual calls and source hashes.
4. [Evidence](evidence.md): reported arithmetic, inference and missing evidence.
5. [Proposal v1](proposal-v1.md): a plausible-sounding claim with an unresolved mechanism overlap.
6. [Original review](review-original.md): a demonstration of a neutral review that exposes the issue.
7. [Response](review-response.md) and [Proposal v2](proposal-v2.md): repair the question and define the smallest useful control.
8. [Decision](decision.md): planned pilot, no experimental result or review approval claimed.

The source has Markdown section anchors instead of PDF page numbers. A real run would record
actual provider/model/route receipts, source page coverage, costs and original outputs.
The two synthetic readers do not count as two actual models. This example illustrates the record
format and a failure/revision path; it is not a claim of scientific novelty.
